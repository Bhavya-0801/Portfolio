HCI PROJECT
PROJ // 05 2025 · HCI / HARDWARE

Hand Gesture Mouse

Touch-Free Mouse Control via MPU6050 & Arduino

A gesture-based mouse control system using an MPU6050 accelerometer sensor and Arduino Nano. Hand movements are captured via accelerometer data and transmitted to a PC through serial communication. A Python script processes the data to control cursor movement and clicks in real time — enabling touch-free human-computer interaction.

What I Learned
Bridging the hardware/software gap: reading raw IMU sensor data, parsing serial streams in Python, and mapping physical gestures to OS-level input events.
Python Arduino Nano MPU6050 IMU Serial Communication HCI

3-Axis Robotic Arm with Arduino Uno & Servo Motors

A beginner-friendly yet fully functional 3-Axis Robotic Armbot designed and built using an Arduino Uno, three SG90 servo motors, and a breadboard. The project explores the fundamentals of servo motor control, inverse kinematics, and how 3-axis robotic systems operate in real life.
